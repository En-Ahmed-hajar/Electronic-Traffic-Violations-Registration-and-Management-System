# نظام تسجيل وإدارة المخالفات المرورية إلكترونيًا

**Electronic Traffic Violations Registration and Management System**

مشروع تخرج مقدم إلى **الجامعة الوطنية -- كلية العلوم والهندسة -- فرع
الحديدة، اليمن**، لنيل درجة البكالوريوس في تقنية المعلومات (IT)، للعام
الجامعي **2025--2026م**.

------------------------------------------------------------------------

## نبذة عن المشروع

نظام إلكتروني يهدف إلى تطوير عملية تسجيل وإدارة المخالفات المرورية،
والحد من الاعتماد على الإجراءات الورقية التي قد تؤدي إلى التأخير وصعوبة
الأرشفة وزيادة احتمالية الأخطاء البشرية.

يوفر النظام بيئة عمل مترابطة تتكون من لوحة تحكم إدارية، وتطبيق ميداني
لرجال المرور، وتطبيق للمواطنين. كما يراعي إمكانية استمرار تسجيل البيانات
عند انقطاع الإنترنت، ثم مزامنتها مع قاعدة البيانات المركزية عند عودة
الاتصال.

## مكونات النظام

### 1. لوحة تحكم إدارة المرور

مخصصة لمسؤولي النظام، وتوفر الوظائف التالية: - تسجيل الدخول إلى لوحة
التحكم. - إدارة حسابات المستخدمين. - إدارة أنواع المخالفات. - إدارة
المخالفات المسجلة. - متابعة البيانات وإصدار التقارير والإحصائيات.

### 2. تطبيق رجال المرور

تطبيق ميداني يساعد رجال المرور على: - تسجيل الدخول. - تسجيل المخالفات
أثناء العمل الميداني. - عرض المخالفات المسجلة. - حفظ البيانات محليًا عند
عدم توفر الإنترنت. - مزامنة البيانات مع قاعدة البيانات المركزية عند توفر
الاتصال.

### 3. تطبيق المواطنين

يتيح للمواطنين: - تسجيل الدخول إلى التطبيق. - الاستعلام عن المخالفات
المرورية. - عرض تفاصيل المخالفات المسجلة. - تلقي الإشعارات المتعلقة
بالمخالفات.

## أهداف المشروع

-   تحسين سرعة ودقة تسجيل المخالفات المرورية.
-   تقليل الأخطاء الناتجة عن الإدخال اليدوي.
-   تسهيل أرشفة المخالفات والبحث عنها واسترجاعها.
-   تعزيز الشفافية والتواصل بين إدارة المرور والمواطنين.
-   تمكين رجال المرور من تسجيل المخالفات ميدانيًا.
-   توفير تقارير تساعد الإدارة في المتابعة واتخاذ القرارات.
-   دعم العمل في البيئات التي تعاني من ضعف الاتصال بالإنترنت.

## التقنيات والأدوات

بحسب وثيقة المشروع، تشمل التقنيات والأدوات المعتمدة في تصور النظام:

-   **Flutter:** لتطوير تطبيقات الأجهزة الذكية.
-   **Laravel:** إطار عمل لتطوير جانب الويب والخدمات الخلفية.
-   **Database:** قاعدة بيانات محلية وأخرى مركزية.
-   **Visual Studio Code:** بيئة تطوير.
-   **Android:** منصة تشغيل تطبيقات الهواتف المستهدفة.

> ملاحظة: قد تختلف تفاصيل التنفيذ الفعلية أو إصدارات الأدوات بحسب ملفات
> المشروع المرفوعة. يُرجى الرجوع إلى ملفات كل تطبيق وملفات الإعداد الخاصة
> به لمعرفة الإصدارات ومتطلبات التشغيل الدقيقة.

## آلية العمل العامة

1.  يسجل رجل المرور الدخول إلى التطبيق الميداني.
2.  يدخل بيانات المخالفة ويحفظها.
3.  إذا كان الاتصال بالإنترنت متاحًا، تُرسل البيانات إلى النظام المركزي.
4.  إذا لم يكن الاتصال متاحًا، تُحفظ البيانات محليًا لتتم مزامنتها لاحقًا.
5.  تتمكن الإدارة من متابعة المخالفات وإدارتها من لوحة التحكم.
6.  يستطيع المواطن الاستعلام عن المخالفات المسجلة وتلقي الإشعارات
    المتعلقة بها.

    المستودع.

-   اتصال بالإنترنت لمزامنة البيانات واستخدام الخدمات المركزية.

## تشغيل المشروع

المستودع قد يحتوي على أكثر من تطبيق؛ لذلك شغّل كل جزء من مجلده المستقل.

### تطبيق Flutter

``` bash
flutter pub get
flutter run
```

لبناء نسخة Android:

``` bash
flutter build apk --release
```

### جزء Laravel 

انتقل إلى مجلد Laravel ثم نفّذ:

``` bash
composer install
```

أنشئ ملف إعدادات البيئة اعتمادًا على الملف النموذجي إن وجد:

``` bash
cp .env.example .env
```

بعد ضبط بيانات قاعدة البيانات داخل `.env`:

``` bash
php artisan key:generate
php artisan migrate
php artisan serve
```

> لا ترفع ملف `.env` أو كلمات المرور أو مفاتيح API أو بيانات قواعد
> البيانات الحقيقية إلى GitHub. استخدم `.env.example` بقيم توضيحية فقط.
